# Iris Flower Classification Using Keras

A deep learning project that classifies iris flowers into three species — *Setosa*, *Versicolor*, and *Virginica* — using a neural network built with Keras and TensorFlow.

---

## Dataset

- Source: UCI Machine Learning Repository
- 150 samples with 4 features:
  - Sepal Length, Sepal Width, Petal Length, Petal Width
- Target classes:
  - Setosa (0), Versicolor (1), Virginica (2)

---

## Model Summary

- Built with Keras Sequential API
- Layers: Dense (ReLU), Output (Softmax)
- Loss: Categorical Crossentropy
- Optimizer: Adam
- Metrics: Accuracy

---

## Project Highlights

- Performed EDA with Seaborn and Matplotlib
- Encoded target with one-hot encoding
- Normalized features using StandardScaler
- Achieved >95% accuracy on test set
- Evaluated using confusion matrix and classification report
